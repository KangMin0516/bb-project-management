# 공통 템플릿 (Shared Templates)

산출물 작성 시 사용하는 공통 템플릿입니다.

## 보고서 헤더

```
# Stage N: [스테이지명] 보고서
- **작성 일시**: [자동 생성]
- **대상 서비스**: [서비스 목록]
- **이전 스테이지**: [참조한 산출물]
```

## 테스트 케이스 형식

```
| ID | Scenario | Input | Expected |
|----|----------|-------|----------|
| XX-1 | Description | Data | SUCCESS / FAIL: message |
```

## 버그 리포트 형식

```
### Bug: [제목]
- **심각도**: Critical / Major / Minor
- **재현 절차**: 1, 2, 3...
- **기대 결과**: ...
- **실제 결과**: ...
- **관련 파일**: 파일:라인
```

## 심각도 분류

- **Critical**: 즉시 대응 (보안 취약점, 데이터 손실, 서비스 다운)
- **Major/Warning**: 수정 권장 (성능 이슈, 잠재적 버그, 핵심 기능 오류)
- **Minor/Info**: 참고 (개선 제안, 비핵심 기능 오류, UI 깨짐)

## 에러 복구 테이블 형식

```
| 상황 | 복구 흐름 |
|------|-----------|
| [상황 설명] | → [슬래시 커맨드 경로] |
```

## 배포 체크리스트 형식

```
### 사전 조건
- [ ] 모든 테스트 통과 (Stage 4)
- [ ] 코드리뷰 승인 (Stage 3)
- [ ] 프로덕션 빌드 성공
- [ ] 환경변수 변경사항 확인

### 서비스별
- [ ] Docker 이미지 빌드 가능
- [ ] DB 스키마 변경 확인
- [ ] API 하위 호환성 확인

### 인프라
- [ ] Docker Compose 설정 변경 여부
- [ ] 포트/볼륨 변경 여부
```
