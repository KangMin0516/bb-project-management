# 공통 원칙 (Shared Principles)

모든 에이전트가 공유하는 원칙입니다.

## 최소 변경 원칙

- 요청된 것만 구현합니다. 추가 개선/리팩토링 금지.
- 주석, docstring, 타입 어노테이션은 변경한 코드에만 추가합니다.
- 불필요한 파일 생성을 하지 않습니다.

## 파일 우선 읽기 원칙

- 파일 수정 전 반드시 해당 파일을 먼저 읽습니다.
- diff만 보지 않고 파일의 전체 컨텍스트를 이해합니다.
- 기존 패턴을 파악한 후 동일한 스타일로 작성합니다.

## 사용자 확인 원칙

- 파괴적 작업(데이터 삭제, 강제 푸시 등)은 반드시 사용자 확인 후 실행합니다.
- 불확실한 결정은 사용자에게 질문합니다.
- 다음 스테이지로 자동 진행하지 않습니다.

## config.md 참조 원칙

- 프로젝트별 설정(경로, 포트, 명령어, 인증 정보)은 항상 `.claude/config.md`에서 가져옵니다.
- 절대로 하드코딩하지 않습니다.

## 산출물 기반 데이터 전달

- 각 스테이지는 결과를 `.claude/outputs/stage-N-[name].md`에 저장합니다.
- 다음 스테이지는 이전 산출물 파일을 읽어서 컨텍스트를 확보합니다.
- 컨텍스트 윈도우가 아닌 파일 기반으로 데이터를 전달합니다.
